Open Research Tools

Open Research Tools is an open-source project building local-first AI systems that convert unstructured sources (e.g., audio, images, web content, and scholarly articles) into structured, searchable datasets, alongside analysis tools to extract and analyse data at scale.

Transcribe Offline v1.2

Transcribe Offline is a free, open source desktop app that runs entirely on your own hardware, producing high-quality transcripts, speaker-attributed text (diarisation) and timestamped subtitles without sending audio to any cloud service or paying per-minute fees. Engine

OpenResearchtools Engine is an early-stage local AI runtime built to be embedded directly into applications, with a small footprint and one consistent stack for chat, vision, embeddings, reranking, transcription/diarisation, and PDF-to-markdown workflows. It is largely based on open-source Llama.cpp and ships as a native in-process runtime.

We also ship a Rust CLI example to accelerate application embedding.
